# JAVA Problem Solving Repository

## 📜 Description

This repository contains a collection of Java programs focused on **problem-solving, data structures, algorithms, and basic Java concepts**. These programs were written to practice coding skills, solve algorithmic challenges, and improve proficiency in Java.

## 🗂️ Contents

The repository includes solutions for various types of problems such as:

-  Arrays & ArrayList manipulation
-  String processing
-  Searching & pattern matching
-  HashMaps and Hashing
-  Mathematical problems
-  Stack examples
-  Algorithmic problem-solving patterns

## 🚀 How to Run

1. Install Java (version 8 or higher recommended).
2. Compile the file you want to run:

```bash
javac filename.java
```
3. Run the compiled file:
```bash
java filename
Example:
javac 2_helloworld.java
java 2_helloworld
```
